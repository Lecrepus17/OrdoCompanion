## 💡 Dicas para Melhores Capturas
- **Formato:** `.png` ou `.webp` (máxima nitidez de texto e elementos da UI).
- **Resolução Recomendada:** Screenshots de celular (ex: 1080x2400) ou capturas da versão Web / Tablet.
- **Tema:** O tema padrão do app (Escuridão ou Conhecimento) fica com excelente contraste no GitHub.
- **Como adicionar:**
  1. Tire o print da tela no emulador ou celular.
  2. Cole o arquivo aqui em `docs/screenshots/` com o nome correspondente (ex: `01-compendio.png`).
  3. Ou simplesmente envie o print no chat que eu posiciono e vinculo no projeto para você!
